# API Health Monitor

Backend-сервис для мониторинга доступности HTTP-эндпоинтов с сохранением результатов проверок в PostgreSQL.

## О проекте

API Health Monitor — проект на Go, предназначенный для периодической проверки доступности заданных URL и хранения результатов этих проверок.

## Технологии

- **Go** — язык разработки.
- **PostgreSQL** — база данных.
- **pgx** — драйвер PostgreSQL и пул соединений.
- **Docker Compose** — запуск локального окружения.
- **golang-migrate** — управление миграциями БД.
- **slog** — структурированное логирование.

## Текущий статус

Реализованы начальная схема БД, конфигурация подключения к PostgreSQL и CRUD-операции репозитория для отслеживаемых эндпоинтов.

В ближайшем времени — HTTP API, периодические проверки доступности, сохранение истории проверок и обработка результатов.
